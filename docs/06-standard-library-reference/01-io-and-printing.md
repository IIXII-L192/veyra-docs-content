# I/O & Console Functions

Standard console I/O functions available in global scope:

- `print(...args)`: Prints arguments without newline.
- `println(...args)`: Prints arguments with newline.
- `input(prompt = "") -> string`: Reads a line from stdin.
- `input_int(prompt = "") -> int64`: Reads an integer from stdin.
- `input_float(prompt = "") -> double`: Reads a float from stdin.
