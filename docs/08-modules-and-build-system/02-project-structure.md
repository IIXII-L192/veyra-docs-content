# Project Structure & veyra.toml

Standard directory layout for Veyra projects:

```text
my_project/
├── veyra.toml        # Project metadata & build settings
├── src/
│   ├── main.vey      # Entry point
│   └── engine/
│       └── core.vey
├── include/          # Native C/C++ header files
└── tests/
    └── test_all.vey
```
