# Syntax & Block Structure

Veyra uses clean, readable statement syntax with braces `{ ... }` for block scoping.

---

## 💬 Comments

```veyra
# Python-style single line comment
// C-style single line comment

/*
   Multi-line C-style block comment
*/
```

---

## 🧱 Statements & Blocks

- Semicolons `;` are optional. Newlines delimit statements.
- Blocks are enclosed in `{ ... }`.

```veyra
let score = 95

if score >= 90 {
    println("Grade: A")
    println("Outstanding work!")
}
```
