# While & For Loops

---

## 🔁 While Loops

```veyra
let mut counter = 5
while counter > 0:
    println("Countdown: {counter}")
    counter -= 1
println("Launch!")
```

---

## 🔄 Range-Based For Loops

```veyra
# Iterates 0, 1, 2, 3, 4
for i in range(5):
    println("i = {i}")

# Iterates 10 to 20 with step 2
for i in range(10, 20, 2):
    println("Even: {i}")
```
