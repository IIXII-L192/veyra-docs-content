# 📖 Veyra Documentation Content (Open Source)

This repository contains the official, open-source markdown content and reference documentation for the **Veyra Programming Language**.

## Contributing to Docs

We welcome contributions, translations, tutorial additions, and corrections!

1. Fork this repository.
2. Edit markdown files under `docs/`.
3. Submit a Pull Request.

The live website that renders this content is available at [docs.veyra-lang.org](https://docs.veyra-lang.org).
