---

## 📂 Documentation Structure (12 Modules)

1. `01-getting-started`: Philosophy, Windows/macOS/Linux setup, CLI command reference.
2. `02-language-fundamentals`: Grammar, scalar types, variables, mutability, operators, string interpolation.
3. `03-control-flow`: `if/elif/else`, `while`, range loops, `enumerate()`.
4. `04-functions-and-closures`: Signatures, pass-by-reference `&mut`, arrow lambdas, generics.
5. `05-data-structures-and-collections`: `vec[T]`, `map[K, V]`, `set[T]`, `pair[A, B]`.
6. `06-object-oriented-programming`: Structs, classes, constructors (`init`), inheritance, operator overloading.
7. `07-memory-model-and-pointers`: Deterministic RAII (`drop`), raw pointers `*T`, address-of `&`.
8. `08-modules-and-build-system`: `import` system, project organization, `veyra.toml`.
9. `09-exhaustive-standard-prelude-reference`: Complete API reference for I/O, strings, math, files, and time.
10. `10-c-and-cpp-interoperability`: `cinclude <header>`, inline `cpp { ... }` blocks.
11. `11-practical-recipes-and-guides`: High-performance CLI tools, 60 FPS Raylib game demo.
12. `12-migration-and-faq`: Python-to-Veyra translation dictionary and troubleshooting.
